不満を抱えた研究者がWindowsゼロデイ公開、System権限奪取の恐れ

Windows 0-day dropped by disgruntled researcher hands hackers System rights

Microsoftと公然と対立している「Nightmare Eclipse」を名乗る研究者が、「SignDrop」と呼ばれる新たなWindowsゼロデイ脆弱性を公開した。この脆弱性は、一部のWindows環境でローカルユーザーに完全なSystem権限を与えてしまう。

背景：脆弱性はCommon Log File System（CLFS）に存在し、Windows Defenderなどの特権プロセスに細工したCLFSコンテナを開かせることで、通常ユーザー権限の攻撃者がSystem権限へ昇格できる。皮肉なことに、この問題はMicrosoftが2025年10月に他のCLFS脆弱性対策として導入したセキュリティ機能自体が原因となっている。

  • 攻撃者はWindows Defenderのシグネチャ更新処理関数ServerMpUpdateEngineSignatureを悪用し、標準ユーザーが作成したログファイルをDefenderに開かせる
  • Windowsオブジェクトマネージャーのシンボリックリンクを操作することで、DefenderがアンチマルウェアエンジンのセキュリティコンテキストでCLFSコンテナを開くよう仕向ける
  • 関連する認証ファイルが存在しない場合、CLFSはSystem権限を持つDefenderの権限で新規ファイルを作成し、そのファイルが元ファイルのDACLを引き継ぐため、攻撃者がSystem権限で作成されたファイルへアクセスできてしまう

なぜ重要か：正規のセキュリティ対策そのものが新たな攻撃経路となる皮肉な事例であり、研究者とMicrosoftとの対立が続く中でゼロデイが次々と公開されている状況は、パッチ適用の遅れや組織内のセキュリティ運用体制に深刻な影響を及ぼす可能性がある。
