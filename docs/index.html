  • 無症状者を対象とした一律検査は、臨床的に妥当性が低いとされる理由を、この研究結果が裏付けている。

なぜ重要か：義務的スクリーニングにより多数の兵士が不必要な医療介入を受ける可能性があり、医学的エビデンスに基づかない政策が軍の健康管理に広範な悪影響を及ぼす恐れがある。
