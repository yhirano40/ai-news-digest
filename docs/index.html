  • 車輪型ロボットや飛行ドローンに比べ、腕や手を持たない四足ロボットの実用用途は限定的で、研究・エンターテインメント用途が中心。
  • Unitreeは四足ロボットで培った低コスト技術を応用し、1万3500ドルからのヒューマノイドロボットも展開。2026年8月19日の上海市場上場では初日に株価が5倍以上急騰し、時価総額340億ドルに達した。

なぜ重要か：Unitreeの低価格戦略は、四足ロボットからヒューマノイドロボットへと市場を広げつつあり、価格破壊が新たな用途や普及を生む可能性を示す一方、米国では法的規制の対象にもなっており、今後の産業動向や米中の技術覇権競争にも影響を与えると見られる。
