Embedded AI evaluators won’t be an easy solution, Hugging Face’s policy chief says

Hugging Faceの政策責任者アイリーン・ソレイマン氏がTechCrunch Disruptで、AIモデルのベンチマーク手法はまだ未成熟であり、組織内に第三者評価者を置く「埋め込み評価者」方式も容易な解決策にはならないと述べた。

背景：AI企業は安全性インシデントの多発を受け、政府規制の代わりに第三者による評価者をラボ内部に置く手法を推進してきたが、その中立性や実効性には疑問の声が上がっている。AnthropicがAccentureを初の評価者として起用した際も、同社の適格性を巡って批判が相次いだ。

  • 評価結果の信頼性には再現性が重要であり、モデルへのアクセス権限（オープンウェイトなど）が鍵を握るとソレイマン氏は指摘。
  • 評価手法間の比較基準が未確立で、評価者としての資格要件の標準化が急務とされる。
  • 評価対象がモデル単体からハーネスやエージェントを含むシステム全体へ移行しつつあるが、ハーネスやエージェント評価はコストが高く、手法の整備が遅れている。

なぜ重要か：ベンチマークが業界で信頼される指標であり続けるには、評価手法と評価者資格の統一的な基準づくりが不可欠であり、これが今後のAI安全性評価の実効性を左右する重要な課題となる。

ReactOS、NTFSへの直接インストールに対応し大きな節目達成

ReactOS reaches major milestone with NTFS install support

オープンソースのWindows代替OS「ReactOS」が、NTFSパーティションへの直接インストールに対応したことが発表された。Phoronixが報じた。

背景：これまでReactOSはインストール時にFAT32パーティションを必要としており、1993年のWindows NT 3.1に遡るMicrosoft独自のNTFS形式（Windows XP以降標準）への対応は、Windows Server 2003とのバイナリ互換性を目指す同プロジェクトにとって長年の課題だった。

  • 新しいNTFSドライバーによりFAT32パーティションへの依存から脱却し、より現代的なWindows環境の再現に前進した。
  • ただし新ドライバーはキャッシング非対応で性能面に課題があり、ジャーナリング機能やセキュリティ機能も未実装の状態にある。
  • ReactOSチームはX（旧Twitter）での発表で「未発見のバグが潜んでいる可能性がある」と注意喚起しており、実用利用にはまだ慎重さが求められる。

なぜ重要か：長年のハードルだったNTFS対応が実現したことで、ReactOSはベータ版リリースに向けて一歩前進し、Windows互換オープンソースOSとしての実用性向上が期待される。

AIクローンへの懸念、インディー開発者が作品公開に及び腰に

AI game clones are making indie developers afraid to show their work

AIコーディングツールによるゲームの模倣が容易になったことで、インディー開発者が早期作品の公開を躊躇するようになっている。開発会社Alliance Artsは、Steam Next Festでのデモ公開を延期し、限定公開に切り替えた。

背景：ゲーム業界は昔から競合作品のクローン制作が行われてきたが、原作者への敬意や模倣の度合いには差があった。しかしAIツールの登場により、ゲームの外観や仕組みを短期間で複製できるようになり、開発者の警戒感が高まっている。

  • Alliance Artsは悪魔テーマのロシアンルーレット型飲酒ゲーム「Drunken Goddess Reflux」の公開デモを中止し、配信・投稿ルールに同意した相手にのみ非公開セッションで共有する方針に転換した。
  • 「Papers, Please」の開発者Lucas Popeも、開発中の内容をAIに模倣されることを懸念し、制作過程を公にしなくなったと語った。
  • 開発者Freya Holmérは3月、回転軸型テトリスのプロトタイプ動画がSNSで話題になった直後、AIで“バイブコーディング”された模倣版が先に公開され、自身の正式リリース前に競合品が出回る事態に直面した。

なぜ重要か：AIによる高速模倣は、独自アイデアの先行者優位を揺るがし、インディー開発者の創作意欲やオープンな情報共有文化を損なう恐れがある。今後、知的財産保護や開発プロセスの公開戦略の見直しが業界全体で求められる可能性がある。

ディズニー、Character.AIを訴訟リスク抜きで事実上買収

Disney found a way to buy Character.AI without buying its lawsuits

ディズニーがチャットボット企業Character.AIの従業員の大半とCEOを引き抜き、技術ライセンスを取得する一方、同社を破産させることで安全性をめぐる訴訟や規制当局の調査責任を回避する「リバース・アクハイア」取引を実行した。

背景：Character.AIは未成年者の自殺事案を含む複数の訴訟や各国規制当局の調査に直面しており、現金準備の減少と訴訟リスクを理由に、ディズニー側はチャプター11破産手続きを通じた取引の完全実行を要求していた。

  • 9月の第一段階取引でディズニーは550万ドルと返金可能な200万ドルの保証金を支払い、CEOを含む従業員の大半を雇用
  • 破産手続きを通じて、信頼・安全モデレーション、年齢推定技術などのコードやツールに対する永続的・世界的な非独占ライセンス取得を目指し、落札すれば追加で1250万ドルを支払う計画
  • 裁判所命令案では本取引を合併とみなさず、Character.AI側に既存の法的責任を残す構造とされ、2024年のGoogleとの類似取引（27億ドル）に続く同社2度目のリバース・アクハイア

なぜ重要か：買収と見なされないよう設計されたこの手法は独占禁止法上の届出義務を回避しつつ、訴訟・規制リスクを買収先企業に残すAI業界特有の構造を象徴しており、議会やFTCなど規制当局の警戒を強める可能性がある。
